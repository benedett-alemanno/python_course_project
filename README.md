# python_course_project
simple python project
Questo progetto consiste nella realizzazione di una classe Python chiamata `Studente` che permette di memorizzare informazioni personali e gestire i voti degli esami.

La classe `Studente` include:

- **Attributi:**
  - nome
  - città di residenza
  - età
  - matricola
  - lista dei voti

- **Metodi:**
  - `presentati()` → restituisce una descrizione dello studente
  - `aggiungi_voto(voto)` → aggiunge un voto (18–30)
  - `calcola_media()` → calcola la media dei voti
  - `studia_ore(ore)` → simula le ore di studio
